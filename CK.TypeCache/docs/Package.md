# CK.TypeCache

The assemblies of the BinPaths and the cache of their types (`AssemblyCache`, `GlobalTypeCache`, `ICachedType`): the
types and their attributes, read once and shared by the engines and the tools that compute type sets.

See the [README](https://github.com/signature-opensource/CK-ResourceSpace/blob/stable/CK.TypeCache/README.md).
