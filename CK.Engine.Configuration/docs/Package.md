# CK.Engine.Configuration

The configuration of the CKomposable engine (`EngineConfiguration`, `BinPathConfiguration`, `TypeSetConfiguration`,
the aspects' configurations) and the App builder model that produces it from a `ckonf.json` (`AppBuilderConfiguration`,
`AppConfiguration`, the `IAppBuilderContributor` contract).

See the [README](https://github.com/signature-opensource/CK-ResourceSpace/blob/stable/CK.Engine.Configuration/README.md).
